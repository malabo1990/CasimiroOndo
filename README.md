# CasimiroOndo

Sitio web de currículum de Casimiro Ondo Obiang — diseño multimedia, interactivo, 3D y accesibilidad.

Sitio estático (HTML/CSS/JS puro) pensado para GitHub Pages. Incluye un botón de alto contraste
y estructura semántica/accesible, ya que el contenido del propio CV está centrado en
accesibilidad y diseño para todos.

## Estructura

- `index.html` — contenido del sitio
- `css/style.css` — estilos (tema oscuro con acentos ámbar, modo alto contraste)
- `js/main.js` — botón de alto contraste + año del pie de página
- `assets/avatar.jpg` — ilustración de perfil (extraída del CV original)
- `assets/CV-Casimiro-Ondo-Obiang.pdf` — versión descargable del CV (3 páginas)

## Desarrollo local

Abrir `index.html` directamente en el navegador, o servirlo con cualquier servidor estático.
